## ⚽ Overview

This application bridges modern interactive tactics board mechanics with the Scottish FA’s four-pillar coaching methodology:
- **The Coach** (Behaviours, Intervention styles, Communication)
- **The Environment** (Culture, Pitch geometry, Session climate)
- **The Player** (Technical, Physical, Psychological, Social / SFA Profiling)
- **The Game** (Tactical principles, Moments of the game, Dynamic scenarios)

---

## 🎯 Key Features

### 1. Dynamic Tier Scaffolding
- **UEFA C Licence**: Fundamental structure, core interventions, technical foundations, and small-sided games.
- **UEFA B Licence**: Units of play, phased transitions, functional practices, and structured phase analysis.
- **UEFA A Licence**: 11v11 macro-tactical strategy, opponent-specific game models, high-level tactical periodisation.

### 2. Interactive Tactical Pitch & Animation Studio
- **SVG Tactical Pitch** with multiple pitch views (Full, Half, Penalty Box, Thirds, Channelled).
- **Player & Equipment Drag-and-Drop**: Place outfield players, goalkeepers, cones, mannequins, goals, and agility poles.
- **Dynamic Drawing Tools**: Solid passes, dashed runs, dribble squiggles, pressing zones, and custom tactical markers.
- **Frame-by-Frame Keyframe Animation Engine**: Record tactical sequences, adjust speed, scrub timeline, and playback in real-time.

### 3. Session & Drill Builder
- Comprehensive metadata capture (Duration, Area dimensions, Pitch zone, Target age group).
- Multi-phase session structuring (Warm-up, Technical, Skill/Functional, Small-Sided Game, 11v11 Game).
- Structured SFA Coaching Points, Interventions, and Key Coaching Questions.

### 4. Scottish FA Methodology Inspector & Validation
- Real-time coaching methodology checks.
- Alignment with SFA's "What, Where, Who, When, Why" game analysis framework.
- Export to JSON and Print/PDF-ready session plan sheets.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- Git

### Installation
```bash
git clone https://github.com/oliveannandale-max/scottish-fa-tactics.git
cd scottish-fa-tactics
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
